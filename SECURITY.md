# Security Policy

Please **do not** open public issues for vulnerabilities.

Report them privately via GitHub's "Report a vulnerability" (Security → Advisories) on this repository. We aim to acknowledge reports within 72 hours and to provide a fix or mitigation timeline within 14 days.

Supported versions: the latest release on `main`.

See [docs/03-security/security.md](docs/03-security/security.md) for the security architecture.
